# Spiking Max-Former (SPaRG-MF) Changelog

## V0.5.0 - Advanced Pruning, Metrics, and Optimization (Current)
- **`models/dynamic_gate.py`**: Added support for per-instance routing (replaces batch-averaging to allow input-dependent masks), time-dependent gating per SNN simulation step, and alternative parameter-free token gating policies (Magnitude-based L2 channel norm and Attention-weighted saliency).
- **`models/mixer_hub.py` & `models/soft_sparse_ssa.py`**: Integrated Top-k and absolute thresholding for linear attention (`SoftSparseSSA`) and softmax attention (`SpikingSoftSparseSelfAttention`) to enable attention sparsification. Added tracking for Q, K, and V states to enable alignment analysis.
- **`models/maxformer_snn.py`**: Configured staged token keep ratios (`token_keep_ratio` as a list of ratios per block) and integrated the new per-instance, temporal, and alternative gating policies.
- **`engine/ssa_interceptor.py`**: Added Q-value computation (Query-Key cosine correlation), head redundancy metrics (pairwise head correlation), attention Shannon entropy, and spike Bernoulli entropy to evaluate attention head health and prevent hallucinations.
- **`engine/regularization.py`**: Created `DiversityLoss` to penalize cross-head correlation during training, forcing heads to learn orthogonal features.
- **`engine/inference_pruning.py`**: Authored post-training calibration and dynamic gating sweeps to evaluate accuracy vs. head sparsity and generate static hardware masks.
- **Optimization Tweaks**:
  - Lowered `DiversityLoss` weight from `0.01` to `0.001` in notebook model configurations to give the network more representation flexibility.
  - Adjusted staged token keep ratios from `[0.9, 0.7, 0.5]` to `[0.95, 0.90, 0.85]` to prevent information/voltage starvation in deep stages.
  - Lowered S_MLP homeostasis target firing rates to `0.15` (fc1) and `0.08` (fc2) in `models/mixer_hub.py` to prevent threshold explosion and enforce sparser, cleaner semantic maps.
  - Resolved `AttributeError: total_mem` in notebook GPU initialization cell.
- **`test_advanced_pruning.py`**: Created a comprehensive dynamic test suite validating all advanced features, staged ratios, and Pareto evaluation sweeps.

## V0.4.0 - ImageNet Scale out & `timm` Integration
- `models/maxformer_snn.py`: Applied `@register_model` to all our factory configurations (`sparg_mf_10_384`, `sparg_mf_10_512`, `sparg_mf_10_768`). The models can now be instantiated natively anywhere using `timm.create_model('sparg_mf...`, completely bridging out the SNN implementation into PyTorch's broader ecosystem.
- `train_imagenet.py`: Authored an official ImageNet-1K PyTorch DDP training entry point heavily adapted from standard scaling heuristics. Native hooks into `timm` for dataset prefetching, `MixUp`/`CutMix` augmentations, AutoCast (AMP), scheduling, and Cross-GPU metrics reduction while guaranteeing that `functional.reset_net(model)` wipes SNN memory buffers cleanly between inference steps.

## V0.3.2 - Homeostasis & CIFAR-10 Training Pipeline (Current)
- `models/homeostasis.py`: `HomeostaticLIFNode` now correctly inherits from `spikingjelly.activation_based.base.MemoryModule` to ensure that `functional.reset_net()` effectively resets the internal buffer states between batches.
- `models/mixer_hub.py`: The core SNN feedforward network (`S_MLP`) has been upgraded to natively utilize `HomeostaticLIFNode`. This directly translates to automatic sparsity regulation—penalizing exploding gradients/overshooting and exciting dormant pathways—across both early DWC stages and downstream SSA blocks.
- `train_cifar10.py`: Created a fully-functional CIFAR-10 training harness demonstrating instantiation of a lightweight 3-stage SpikingMaxFormer configured for 32x32 image inputs, complete with optimization, cosine annealing logic, standard augmentation, and SNN memory resetting operations.

## V0.3.0 - Full Hierarchical Max-Former Architecture (Current)
- Rewrote `models/patch_embed.py`:
    Now faithfully reproduces the NeurIPS 2025 Max-Former embedding strategy.
    Embed_Orig_ImageNet: 4-conv stem with membrane shortcuts (224 → 56, ÷4).
    Embed_Max_Stage: MaxPool-based inter-stage downsampler (÷2) with shortcuts.
    Uses flatten(0,1) pattern from original repo for CPU+GPU compatibility.
- Created `models/mixer_hub.py`:
    S_MLP: Spiking MLP using 1×1 convolutions, matching the original paper.
    Mixer_DWC: DepthWise-Conv local mixer with configurable kernel (7, 5, 3).
    Block_DWC: DWC mixer + S_MLP (used in stages 1-2).
    SoftSparseSSA: Faithful spike-driven linear attention (Q^T K @ V) from
        Spikformer, enhanced with learnable temperature and head mask hooks.
    Block_SSA: SSA mixer + S_MLP (used in stage 3).
- Rewrote `models/maxformer_snn.py`:
    Now a proper 3-stage hierarchical architecture matching the paper:
      Stage 1: Embed_Orig_ImageNet → DWC-7 blocks (dim/4, 56×56 tokens)
      Stage 2: Embed_Max (MaxPool ÷2) → DWC-5 blocks (dim/2, 28×28)
      Stage 3: Embed_Max (MaxPool ÷2) → SSA blocks (dim, 14×14)
    SPaRG-MF enhancements (head gating, token gating, mixed precision) are
    applied only to the SSA stage where they matter most.
    Factory functions: sparg_mf_10_384, sparg_mf_10_512, sparg_mf_10_768.
- Rewrote `engine/ssa_interceptor.py`:
    Now hooks into stage3.*.attn.attn_lif (the actual SSA blocks).
    Per-block head importance and token saliency computation.
    generate_hardware_gating_masks() returns a list of per-SSA-block masks.
- Rewrote `test_forward_pass.py`:
    Updated for hierarchical model: tests all 7 steps with small 64×64 config.
- Removed `models/soft_sparse_ssa.py` (replaced by mixer_hub.SoftSparseSSA).
- Removed `models/spiking_maxformer_block.py` (replaced by mixer_hub blocks).
- Updated `models/__init__.py` with new exports.
